Agent Skills marketplace FAQ

What is an Agent Skills marketplace?

An Agent Skills marketplace provides ready-to-run SKILL.md packages for coding agents like Claude Code, Codex, Cursor, and OpenClaw. Unlike scraper directories, every Skill on Skillry is built and verified in-house for slides, websites, videos, and images—with real previews before you install.

Are the Skills on Skillry free?

Every category has free Skills you can install right away, and the rest are included with a Skillry plan. Free and Pro Skills install and run the exact same way.

How do I install a Skill from the marketplace?

Open a Skill, copy its install prompt and paste it into your agent; it puts the Skill in the right folder. You can also download the ZIP or use the Skillry CLI.

Which coding agents do these Skills support?

Every Skill is a standard SKILL.md folder, so it runs in Claude Code, OpenAI Codex, Cursor, OpenClaw, Antigravity and more than 30 other agents that read Agent Skills.

How is Skillry different from a GitHub awesome list or scraper directory?

Scraper directories and GitHub lists only collect unverified links that you have to debug yourself. Skillry is a first-party studio: we build, test, and maintain every Skill ourselves, verify every preview output with real runs, and support one-prompt installation.
