Quick answer

What are Claude Code skills?

Claude Code skills are folders with a SKILL.md file that teach Claude one job. Claude Code reads them from ~/.claude/skills/ for every project and .claude/skills/ inside one repository, and loads a skill automatically when your request matches its description. You can also run one directly with /skill-name.

How to install skills in Claude Code

Every Skillry Skill is a plain SKILL.md folder. Pick whichever way fits how you work.

Copy the install prompt

Recommended

Paste one sentence into Claude Code. It reads the install guide and puts the Skill in the right folder itself.

  1. 1Open any Skill on Skillry and click Copy install prompt.
  2. 2Paste it into Claude Code and send.
  3. 3Approve the sign-in in your browser if asked, then ask for what you need.

Download ZIP

No Node.js needed. Unzip the Skill into the folder yourself.

  1. 1Click Download ZIP on any Skill page.
  2. 2Unzip it so the folder sits in ~/.claude/skills/.
  3. 3Restart Claude Code so it picks up the new Skill.
~/.claude/skills/<skill>/SKILL.md

Skillry CLI

Also works

One command downloads the Skill and puts it where Claude Code looks.

  1. 1Open a terminal in any folder.
  2. 2Run the command with --agent claude-code.
  3. 3Open Claude Code and ask for what you need.

Claude Code skills FAQ

What are the best Claude Code skills?

It depends on what you want Claude Code to make. By installs, the top picks are Field Notes Deck for slides, Cadence Marketing Landing for websites, Velocity-Matched UI Sting for launch videos, and Hand-Drawn Visual Notes for images.

Can I use Claude Code skills in Codex or Cursor?

Yes. A skill is a plain SKILL.md folder, so the same Skill runs in Codex, Cursor and 30 other agents. Only the install folder changes, and the Skillry install prompt picks the right one for the agent you use.

What are skills in Claude Code?

A skill is a folder with a SKILL.md file: a name, a description and instructions, plus optional scripts and assets. Claude Code loads it when your request matches, or when you run /skill-name.

Where is the Claude Code skills folder?

Personal skills go in ~/.claude/skills/ and work in every project. Project skills go in .claude/skills/ inside the repository; commit that folder so your whole team gets the same skills.

Claude Code skills vs plugins: what is the difference?

A skill teaches Claude one workflow. A plugin is a package that can bundle several skills with commands, hooks and MCP servers. Every Skill on Skillry is a plain skill, so it works with or without plugins.

Why does Claude Code not see my skill?

Check that the folder sits directly in ~/.claude/skills/ or .claude/skills/ and that SKILL.md starts with a name and description. A skill installed into ~/.agents/skills/ is invisible to Claude Code.

Are the Skills on Skillry free?
