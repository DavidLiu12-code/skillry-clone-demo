How content creators use Skills

Three steps in Claude Code, Codex or Cursor. No design app needed.

  1. 1

    Paste the install prompt

    Copy the install prompt into your agent, or run the command below. The Skill lands in your agent's skills folder.

    npx skillry-cli@latest install bs-grokbot-avatar
  2. 2

    Call it with a slash

    Type a slash and the Skill name, then say what you want in plain words.

    /bs-grokbot-avatar Turn this product brief into a week of platform-specific social posts.
  3. 3

    Review and ship

    Open the file it made, ask for changes in the same chat, then publish or hand it off.

    image.png

Skills for content creators: FAQ

What are Skills for content creators?

Each Skill is a folder of instructions, layouts and checks that teaches Claude Code, Codex or Cursor to make one kind of deliverable, such as an article cover, a social card or a talking-head video overlay. Your agent follows a finished design instead of improvising one.

Do I need design skills to use them?

No. The design lives in the Skill. You describe what you need in plain words and review the result.

Which agents do they work in?

Claude Code, Codex and Cursor read the same SKILL.md. Each detail page lists every agent the Skill supports.

Are these Skills free?

Some are. Free Skills carry a Free label; the rest are included in Pro or can be bought one at a time.
