The short answer

  1. 1Folders: ~/.claude/skills · ~/.agents/skills (+ older ~/.codex/skills) · ~/.cursor/skills
  2. 2Run one: /name (Claude Code, Cursor) · $name (Codex) · @name attaches it in Cursor
  3. 3See what’s installed: /skills · Customize → Skills
  4. 4Install: npx --yes skillry-cli@latest install <slug>, add --agent claude-code for Claude Code

SKILL.md frontmatter fields

Each Skill has a SKILL.md file, and its settings sit between two --- lines at the top. These are the fields that change how the agent treats it.

FieldLimit / effectClaude CodeCodexCursor
name≤64 chars; a–z, 0–9 and hyphens; matches the folder nameoptionalrequiredrequired
description≤1,024 chars; say what it does and when to use itrecommendedrequiredrequired
allowed-toolsTools it can use without asking (experimental in the spec)yes——
pathsRuns on its own only for matching file patternsyes—yes

Skillry CLI commands

The Skillry CLI downloads a Skill from Skillry and puts it in the right folder for your agent.

CommandWhat it does
skillry-cli loginSigns you in through the browser with a device code
skillry-cli statusShows which account you’re signed in as
skillry-cli install <slug>Installs to ~/.agents/skills/<slug>/
--agent claude-code…installs to ~/.claude/skills/<slug>/ instead
--target <dir>…installs to any Skills folder, e.g. .claude/skills
--forceReplaces an existing copy and keeps a backup
skillry-cli logoutSigns you out and revokes the session

Start each command with npx --yes skillry-cli@latest. Runs on macOS or Windows with Node.js 22+. You can’t use --agent and --target together.
