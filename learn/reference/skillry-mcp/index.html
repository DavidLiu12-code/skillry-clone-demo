Before you call a tool

Add Skillry to your client

Skillry uses a local stdio server on macOS or Windows with Node.js 22+. Credentials stay in the OS keyring. The website URL /mcp is a setup page, not a remote MCP endpoint.

Account and authorization

Account calls use browser authorization with skills:read. The current credential expires after 7 days and has no automatic renewal. CLI and MCP on the same computer share the credential for the same service URL; disconnecting revokes that credential.

Inspect requirements and access before installing. Keep the user's selected Skill and version. Installation never executes the Skill, purchases access or pays an external provider.

Replace <skill-slug> with a slug returned by search_skills and <published-version> with the selected release version. Use absolute paths for your own computer.

Discovery

01 / 03
01

search_skills

Public

Find published Skills by the output you want and explicit requirements. Default retrieval uses keywords; matching does not guarantee that a Skill can run in your setup.

Parameters9

querystringOptional

Desired output or exact name/slug. Describe the result you want; an input PDF or URL does not define the output type.

maxLength: 200 · Default ""

outputTypestringOptional

Filter by the desired output type. presentation is the API value for presentation Skills.

html | image | video | presentation | game | other

deliveryScopestringOptional

Select a complete work or a component. Missing delivery metadata stays subject to review.

complete | component

avoidVoiceoverbooleanOptional

Set true to exclude known core voiceover requirements.

allowApiKeysbooleanOptional

Set false to exclude declared required provider keys. Missing declarations remain unknown.

allowExternalCostsbooleanOptional

Set false to exclude declared external costs. Unknown costs still need review.

limitintegerOptional

Maximum results per call. Use the range and default shown for this tool.

≥ 1 · ≤ 20 · Default 5

offsetintegerOptional

Pagination offset. Continue with the returned nextOffset.

≥ 0 · ≤ 10000 · Default 0

localestringOptional

Content language. Use the exact API locale value, including zh-CN, zh-TW and pt-BR.

en | zh-CN | zh-TW | ja | ko | es | pt-BR | de | fr · Default "en"

Result and behavior

Returns skills, nextOffset and retrieval/review status. Inspect appliedRequirements, requirementReview, costNotice and clarificationQuestion. Unknown requirements need review; constraintsStatus: unconfirmed means the service did not confirm enforcement. Scores are not probabilities.

02

get_skill

Public

Inspect one published Skill's version, preview link, inputs, dependencies and external costs before making a selection.

Parameters1

slugstringRequired

Exact published Skill slug selected by the user; lowercase kebab-case, up to 64 characters.

minLength: 1 · maxLength: 64

Result and behavior

Returns public release metadata. It does not grant access or include private package contents.

Account and authorization

02 / 03
03

connect_account

Browser authorization flow

Start browser account authorization when the user asks to connect. An already pending flow is reused.

Parameters·No arguments. Pass an empty object.

Result and behavior

Returns verificationUrl, userCode, expiresAt, browserOpened and pollAfterSeconds. Show the URL and matching code to the user; credentials are never returned.

04

connection_status

Browser authorization flow

Continue a pending authorization flow. Call again after the returned pollAfterSeconds interval.

Parameters·No arguments. Pass an empty object.

Result and behavior

Reports not_started, pending, denied, expired or connected. After approval, the token is saved in the OS keyring. Respect the polling interval.

05

account_status

Account required

Check current membership, authorization expiry, scope and daily download quota.

Parameters·No arguments. Pass an empty object.

Result and behavior

Returns connected, entitlement, scope, sessionExpiresAt, quota and pricingUrl. Personal identity and credentials are omitted.

06

disconnect_account

Account required

Cancel pending authorization, revoke the shared CLI/MCP credential and remove it from the OS keyring.

Parameters·No arguments. Pass an empty object.

Result and behavior

Inspect serverRevoked. If remote revocation fails, the local credential is removed but the server token may remain usable until expiry.

07

get_skill_access

Account required

Check access to one published Skill before downloading. This check does not reserve or consume a quota slot.

Parameters1

slugstringRequired

Exact published Skill slug selected by the user; lowercase kebab-case, up to 64 characters.

minLength: 1 · maxLength: 64

Result and behavior

Returns access (free, purchased, member or purchase_required), canDownload, reason, purchaseUrl, version and quota. Download checks permissions again.

Downloads, installation and updates

03 / 03
08

download_skill

Account requiredChanges local files

Save a verified Skill ZIP in a chosen absolute download directory. Existing files are never overwritten.

Parameters3

slugstringRequired

Exact published Skill slug selected by the user; lowercase kebab-case, up to 64 characters.

minLength: 1 · maxLength: 64

downloadDirectorystringRequired

Explicit absolute directory for saving the ZIP. No agent or installation scope is used.

maxLength: 4096

expectedVersionstringOptional

Selected published version. Required for updates; optional for installation/download. A changed release must be reviewed before continuing.

minLength: 1 · maxLength: 64

Result and behavior

Returns archivePath, slug, version and sha256 after ZIP integrity and release checks. Does not install or report an installation.

09

install_skill

Account requiredChanges local files

Install the selected release into an explicitly chosen agent and scope. Existing Skill directories are not overwritten.

Parameters5

slugstringRequired

Exact published Skill slug selected by the user; lowercase kebab-case, up to 64 characters.

minLength: 1 · maxLength: 64

agentstringRequired

Installation target, not the MCP host name. Global targets use their configured Skills directory. Project scope accepts shared or claude-code only.

shared | codex | cursor | gemini-cli | opencode | claude-code | kimi-code | antigravity

scopestringOptional

global installs for your OS user. project installs under the explicit projectDirectory.

global | project · Default "global"

projectDirectorystringOptional

Absolute project path, required with scope: project and disallowed with scope: global. shared uses .agents/skills; claude-code uses .claude/skills.

maxLength: 4096

expectedVersionstringOptional

Selected published version. Required for updates; optional for installation/download. A changed release must be reviewed before continuing.

minLength: 1 · maxLength: 64

Result and behavior

Returns targetPath, skillFile, version, completionReported and inventoryRecorded. Read SKILL.md and review costs before running it.

10

list_installed_skills

Local files

Read Skills in the selected local directory. Only Skillry-managed installations have a recorded release version.

Parameters3

agentstringRequired

Installation target, not the MCP host name. Global targets use their configured Skills directory. Project scope accepts shared or claude-code only.

shared | codex | cursor | gemini-cli | opencode | claude-code | kimi-code | antigravity

scopestringOptional

global installs for your OS user. project installs under the explicit projectDirectory.

global | project · Default "global"

projectDirectorystringOptional

Absolute project path, required with scope: project and disallowed with scope: global. shared uses .agents/skills; claude-code uses .claude/skills.

maxLength: 4096

Result and behavior

Returns local entries and their managed/version status. Unmanaged Skills have unknown versions and cannot be silently upgraded.

11

check_updates

Local files

Compare local managed installations with published releases. Checking does not download or install an update.

Parameters5

agentstringRequired

Installation target, not the MCP host name. Global targets use their configured Skills directory. Project scope accepts shared or claude-code only.

shared | codex | cursor | gemini-cli | opencode | claude-code | kimi-code | antigravity

scopestringOptional

global installs for your OS user. project installs under the explicit projectDirectory.

global | project · Default "global"

projectDirectorystringOptional

Absolute project path, required with scope: project and disallowed with scope: global. shared uses .agents/skills; claude-code uses .claude/skills.

maxLength: 4096

offsetintegerOptional

Pagination offset. Continue with the returned nextOffset.

≥ 0 · ≤ 9007199254740991 · Default 0

limitintegerOptional

Maximum results per call. Use the range and default shown for this tool.

≥ 1 · ≤ 5 · Default 5

Result and behavior

Returns current, update_available, unavailable or unmanaged for each entry, plus nextOffset. Use the same agent and scope when continuing.

12

update_skill

Account requiredChanges local files

Update a Skillry-managed Skill installed on your computer to the version explicitly approved by the user. Back up the entire previous directory, including local edits.

Parameters5

agentstringRequired

Installation target, not the MCP host name. Global targets use their configured Skills directory. Project scope accepts shared or claude-code only.

shared | codex | cursor | gemini-cli | opencode | claude-code | kimi-code | antigravity

scopestringOptional

global installs for your OS user. project installs under the explicit projectDirectory.

global | project · Default "global"

projectDirectorystringOptional

Absolute project path, required with scope: project and disallowed with scope: global. shared uses .agents/skills; claude-code uses .claude/skills.

maxLength: 4096

slugstringRequired

Exact published Skill slug selected by the user; lowercase kebab-case, up to 64 characters.

minLength: 1 · maxLength: 64

expectedVersionstringRequired

Selected published version. Required for updates; optional for installation/download. A changed release must be reviewed before continuing.

minLength: 1 · maxLength: 64

Result and behavior

Returns the installed release and backupPath when a replacement occurs. An already current version is returned without replacement.

Installation directories

Global shared, codex, cursor, gemini-cli, opencode and kimi-code use ~/.agents/skills. claude-code uses ~/.claude/skills. antigravity uses ~/.gemini/config/skills. Project scope uses <projectDirectory>/.agents/skills or <projectDirectory>/.claude/skills. Never infer a project from the MCP process working directory.

Status and recovery

01Missing or expired account authorization
For authentication_required or session_expired, ask the user to connect, call connect_account, show its URL/code and poll connection_status at the specified interval. Retry the original action after approval.
02The Skill directory already exists
For skill_already_installed, inspect the same target with list_installed_skills and check_updates. Ask before updating a managed installation to a selected newer release. MCP has no force argument.
03Purchase or daily quota required
Follow the returned purchaseUrl/actionUrl for purchase_required or premium_required. For daily_download_limit, show resetsAt. Repeated downloads of the same Skill that day do not use another distinct-Skill slot; the day resets at 00:00 UTC.
04No Skillry tools appear
Check Node.js 22+, the selected OS configuration and client logs. Restart or reload the client after adding the server. Browser-only or Linux environments are outside the current supported setup.
