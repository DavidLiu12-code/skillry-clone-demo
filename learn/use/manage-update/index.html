Update, roll back and remove Agent Skills

A Skill is a dependency like any other. Write down where it came from, update it when you mean to, and find out where the backup goes before you need it.

For
People maintaining Skills
Works with
Claude Code, Codex, Cursor
Time
8 min

The short answer

To update a Skillry Skill, run the install command again with --force. The CLI moves your old copy into .best-ai-skills/backups/ next to your Skills and prints where it went. There’s no separate update or uninstall command.

How to update a Skill

You update a Skill by installing it again with --force. The CLI downloads the latest version and replaces the whole folder, so read first and test after:

  1. 1

    Check what changed on the Skill’s page, especially scripts, Dependencies and Outside costs.

  2. 2

    Install again with --force, using the same agent or target as last time. Without the flag, the CLI stops with “already exists. Re-run with --force to replace it safely.”

    You should see: Installed <slug> <version> to … and Previous version preserved at …

  3. 3

    Run your usual test: once by name, once in plain words.

Edited the Skill locally? --force overwrites those edits. Copy them out first, or keep them in references/ so you can re-apply them.

Roll back a bad update

Each forced install leaves the old copy beside your Skills, for example in ~/.agents/skills/.best-ai-skills/backups/<slug>-<date>-<id>/. Agents don’t load that folder. To go back, delete the active <slug>/ folder, move the backup into its place and rename it to <slug>.

If an install fails halfway, the CLI restores the old copy by itself.

Remove a Skill

To remove a Skill, delete its folder. Then search your personal and project folders for another copy with the same name. In Claude Code a personal copy beats a project one, so a leftover can make a later update look ignored. Skill locations lists every folder.

Common questions

How do I update Claude Skills?

Run the Skillry install command again with --force, or replace the whole Skill folder in ~/.claude/skills/. Claude Code picks up the change in the current session.

Why didn’t my Skill update take effect?

Usually another copy with the same name is installed somewhere else, or only SKILL.md was replaced. Search your personal and project Skill folders and keep one complete copy.

How do I roll back a Skill update?

Delete the active <slug>/ folder and move the backup from .best-ai-skills/backups/ into its place, renamed to <slug>. The CLI prints the backup path when you update.

How do I uninstall a Skill?

Delete its folder. The Skillry CLI has no uninstall command, so check for leftover copies with the same name afterwards.
