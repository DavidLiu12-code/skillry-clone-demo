Connect Skillry MCP in Gemini CLI and Antigravity

Gemini CLI registers servers with gemini mcp add; Google’s Antigravity (CLI, app and IDE) reads a shared mcp_config.json instead. Since 18 June 2026 free-tier and Google One users are moved from Gemini CLI to Antigravity CLI, so this page covers both.

For
Gemini CLI and Antigravity users
Time
4 min to complete
Checked
Official docs, 28 Oct 2026

The short answer

  1. 1Gemini CLI: run gemini mcp add --scope user --transport stdio skillry npx -- --yes skillry-cli@latest mcp. Without --scope user it applies to the current project only.
  2. 2Antigravity: merge the skillry entry into ~/.gemini/config/mcp_config.json, then type /mcp in Antigravity CLI.
  3. 3In either tool, /mcp inside a session lists the server and its tools.

Authorize when you install

Installing checks your Skillry account. You do not type a password or paste a key into the agent: the first time, it opens a page in your browser and you approve it there.

  1. 1

    Ask the agent to install the Skill you chose, for example Install it for this project.

    You should see: The agent reports that it needs to connect your account and opens your browser. In a terminal client it may print the link instead; open it yourself.

  2. 2

    Check that the device code on the page matches the one the agent shows, sign in to Skillry if asked, then select Approve.

    You should see: Authorization approved, with a note to return to your agent. The agent notices within a few seconds and finishes the install.

The approval lasts 7 days and is stored in your operating system’s keyring (Keychain on macOS, Credential Manager on Windows). When it expires the agent simply asks you to approve again. To sign out early, ask the agent to disconnect your Skillry account.

If the agent can’t see Skillry

What you seeLikely causeWhat to do
gemini mcp list is empty in another folderThe server was added with the default project scopeAdd it again with --scope user, or move the entry to ~/.gemini/settings.json.
gemini says the CLI has been replacedYour plan was moved to Antigravity CLIUse the Antigravity tab. The entry is the same JSON in a different file.
Antigravity does not pick the file upThe file has a JSON error, or was not refreshedValidate the JSON, then /mcp in the CLI or Refresh in the app.
The server is listed but shows as failed, or never startsnpx is not installed, Node.js is older than 22, or the first start timed out while downloading the packageRun node --version and npx --version in a terminal. Then run npx --yes skillry-cli@latest mcp once by hand, wait for it to start, press Ctrl+C, and try the client again: the package is now cached.
On Windows the server exits as soon as it startsThe entry starts npx directly, and Windows needs a shell to run itUse the Windows entry from this page: the command is cmd and the arguments start with /c, npx.
The browser page says the request is invalid or expiredThe device code was approved too late, or belongs to an earlier attemptAsk the agent to connect again and approve the new code within a few minutes.
Installing stops with a Premium or purchase messageThe Skill is Premium and your account has neither a plan nor a purchase for itFollow the link the agent shows to buy the Skill or subscribe, then ask again. Nothing is charged until you do.

Remove or disconnect

  1. 1

    Gemini CLI: remove the server from your user settings.

  2. 2

    Antigravity: delete the skillry entry from mcp_config.json and refresh. To keep it but stop it loading, set "disabled": true on the entry.

Removing the entry does not sign you out of Skillry. To revoke the stored approval as well, ask the agent to disconnect your Skillry account first, or remove the entry and let the approval expire after 7 days.

Common questions

Is Gemini CLI going away?

Google moved free-tier and Google One users to Antigravity CLI on 18 June 2026; paid plans keep Gemini CLI. The Skillry entry is the same JSON in both tools.

Why --scope user?

Gemini CLI’s default scope is the current project. User scope puts the entry in ~/.gemini/settings.json, so it works in every folder.

Do the Antigravity app and CLI share the entry?

Yes. The app, the CLI and the IDE all read ~/.gemini/config/mcp_config.json.
