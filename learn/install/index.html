How to install Agent Skills

You can install Claude Skills, or any Agent Skill, three ways: paste an install prompt into your agent, run the Skillry CLI, or copy a folder from GitHub or a ZIP. Pick the one that fits where you are, then check the folder landed where your agent looks.

For
People installing a Skill
Works with
Claude Code, Codex, Cursor
Time
9 min

The short answer

  1. 1Agent already open? Use Copy install prompt. Working in a terminal? Use the CLI. Got a folder from GitHub? Copy it in.
  2. 2Claude Code needs --agent claude-code. Codex and Cursor use the default folder, ~/.agents/skills/.
  3. 3You’re done when SKILL.md sits directly inside the Skill’s folder and your agent lists it.

Which method should you use?

Go by where you are right now. All three end the same way, with the Skill’s folder sitting where your agent can find it.

Your agent is open

Copy install prompt on the Skill page, then paste it into the agent

You like working in the terminal

The Skillry CLI (macOS or Windows, Node.js 22+)

You’re on Linux, or want to read the files first

Download ZIP, then copy the folder in by hand

The Skill is on GitHub

Clone or download the repository, then copy the folder in by hand

Where does each agent look for Skills?

Each agent reads Skills from its own folder, and the CLI picks the folder for you. Codex and Cursor both read ~/.agents/skills/, so one install covers both.

How to add Skills to Claude Code, Codex, or Cursor

Open the tab for the method you picked. The first two report the version and folder when they finish; with a manual copy, you check the folder yourself.

Best when your agent is already open
  1. 1

    On the Skill’s page, select Copy install prompt, then Copy in the dialog.

  2. 2

    Paste it into your agent. The agent reads Skillry’s install instructions and runs the right command for itself.

  3. 3

    When asked, approve the device code in your browser.

    You should see: the agent reporting the version it installed and the folder it used.

Best when you’d rather run commands yourself
  1. 1

    Sign in once. A browser window opens and asks you to approve a device code.

  2. 2

    Install the Skill. For Claude Code, add --agent claude-code.

    You should see: Installed <slug> <version> to ~/.agents/skills/<slug>

  3. 3

    Reinstalling later? Add --force. Without it, the CLI stops instead of overwriting your copy.

Skillry never asks you to paste an API key. Your sign-in is stored in the macOS Keychain or Windows Credential Manager.

Best on Linux, or when you want to read the files first

Copy the whole folder, not just SKILL.md. The instructions often point to files that sit next to it.

Right

One level deep

  • ~/.claude/skills/my-skill/SKILL.md
Wrong

An extra level from the ZIP

  • ~/.claude/skills/my-skill/my-skill/SKILL.md
  • or SKILL.md sitting loose in skills/

How do you install a Skill for just one project?

Point --target at the project’s Skills folder. The CLI has no separate project switch, but --target accepts any Skills folder, so run this from inside the repository:

Commit that folder and everyone who clones the repository gets the same Skill.

Use --agent or --target, not both. The CLI rejects the combination.

How to check the install worked

Take thirty seconds to confirm it now, before you need the Skill for real work.

  1. 1Open the folder and make sure SKILL.md is right there, not one level down.
  2. 2List your Skills: /skills in Claude Code and Codex, Customize → Skills in Cursor.
  3. 3Run it once by name.

Not in the list? Troubleshooting walks through every cause.

Common questions

How do I install a Skill with npx?

Run npx --yes skillry-cli@latest install <slug>, and add --agent claude-code for Claude Code. It signs you in through the browser and prints where it installed the Skill.

How do I install Claude Skills from GitHub?

Download or clone the repository, then move the Skill’s folder, with SKILL.md directly inside, into ~/.claude/skills/ or the project’s .claude/skills/.

Can I add Skills to the free version of Claude?

In Claude Code, Codex, and Cursor, a Skill is a folder you install yourself. Whether you can use Skills in the claude.ai app depends on your Claude plan and settings.
