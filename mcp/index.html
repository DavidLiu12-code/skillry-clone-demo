Questions

Straight answers about access, limits and what stays the same.

Do I need an account or API key?

Browse and search without signing in. Downloads and installations use your Skillry purchases or membership and the account's daily quota. Connecting needs no Skillry API key.

Does installation run the Skill?

Your agent runs installed Skills in your own setup. Individual Skills may need extra tools or provider keys; external model and rendering fees are separate.

How long does authorization last?

Account authorization currently lasts 7 days. When it expires, reconnect in your browser. You can disconnect through your agent at any time.

Is there a usage limit?

Each account can load 50 Skills a day across MCP, the CLI and the web. Searching doesn't count. The limit resets at 00:00 UTC.

What happens when my agent asks for a Premium Skill?

It shows the price and a link to buy the Skill for $4.99 or subscribe. Nothing is charged until you say yes.

Can I keep installing Skills the old way?

Yes. The install prompt, the terminal CLI and ZIP downloads all stay.
